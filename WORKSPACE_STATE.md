# TCGate Workspace State

Cette branche n'est ni une branche produit ni une branche de déploiement.

Elle contient la source d'état canonique du workspace TCGate :

- roadmap et maturité des fonctions ;
- historiques ;
- travaux actifs et priorités ;
- décisions ouvertes ;
- Vision Lab ;
- campagnes de qualification de nouvelles BDD.

Le fichier `tcgate_workspace_state.json` est chargé automatiquement par le HTML permanent du workspace.

Règles :

- ne jamais merger cette branche dans `main` ;
- ne jamais connecter Railway à cette branche ;
- mettre à jour le JSON après toute évolution significative du projet ;
- GitHub reste la source de vérité technique de ce qui est réellement intégré ;
- le workspace reste la source de vérité produit, roadmap et historique.
