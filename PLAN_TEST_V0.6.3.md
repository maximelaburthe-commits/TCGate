# Plan de test V0.6.3

Durée recommandée : 15 à 20 minutes.

1. Carte A seule : vérifier détection + identification normales.
2. Carte B déjà détectée puis glissée sous A : recouvrir progressivement 25 %, 50 %, 70 %, 85 %.
3. Carte B NON présentée auparavant : la glisser directement sous A comme en vraie partie.
4. Aligner presque parfaitement A et B, en ne laissant qu’une bande visible.
5. Déplacer ensuite A pour réexposer B : le track/identité doit revenir sans saut inutile.
6. Refaire les cas avec une carte tournée à 90° et avec sleeves.
7. Ajouter quelques reflets naturels pour vérifier que V0.6.2 ne régresse pas.

À noter pendant le test :
- carte perdue ;
- mauvais ID ;
- carte sous-jacente conservée ou non ;
- apparition d’un faux deuxième track ;
- délai avant récupération après retrait de l’occlusion.

À la fin : générer le rapport complet du PC qui analyse le flux adverse.
