# Plan de test — TCGate Alpha 0.1 Candidate 1

1. Utiliser deux PC, idéalement sur deux accès Internet différents.
2. PC A crée un salon TCGate et partage le code.
3. PC B rejoint le salon.
4. Activer webcam et micro sur les deux machines.
5. Vérifier que chacun voit et entend l’autre.
6. Jouer normalement pendant 30 à 60 minutes.
7. Ne pas faire de stress-test artificiel du hover : consulter seulement les
   cartes réellement utiles pendant la partie.
8. Si une carte lisible n’est pas détectée, cliquer `Carte non détectée`.
9. Si une mauvaise carte HD apparaît, cliquer `Mauvaise carte affichée`.
10. À la fin, générer `Rapport complet` sur les deux PC.

## Succès Candidate 1
- partie stable 30–60 min ;
- aucune mauvaise identité persistante ;
- aucun flash d’ancienne carte lors du hover ;
- consultations HD fluides ;
- calibration sans intervention ;
- connexion WebRTC stable ;
- rapport complet généré sur les deux côtés.
