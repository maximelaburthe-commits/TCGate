# Test ciblé — Candidate 11 · UI 1.0.4 corrective

Durée visée : 5 à 8 minutes.

1. **Accueil sur le PC HP**
   - ouvrir TCGate en fenêtre normale ;
   - vérifier qu'aucun bloc ne se chevauche et que les deux actions principales restent lisibles ;
   - si une reprise de partie est proposée, vérifier que la carte de reprise reste elle aussi dans la mise en page.

2. **Gig Dice — position initiale**
   - entrer dans une partie Cyberpunk sans déplacer le panneau ;
   - vérifier que le panneau ne chevauche pas le petit flux local dès son apparition.

3. **Poignée six points**
   - passer la souris plusieurs fois sur les points sans cliquer ;
   - ils peuvent changer de teinte, mais leur position ne doit pas bouger.

4. **Plein écran**
   - passer le flux adverse en plein écran ;
   - agrandir une carte reconnue ;
   - vérifier l'absence de contour/ombre noire parasite autour de la vue agrandie.

5. **Régression rapide**
   - F5 une fois : la partie et les flux doivent revenir ;
   - aucune nouvelle campagne réseau n'est nécessaire si ce point reste vert.

Si ces cinq points passent, conserver Candidate 11 + UI 1.0.4 comme baseline avant préparation de l'alpha privée.
